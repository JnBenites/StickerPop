# StickerPop

Android app that displays animated stickers floating over any app.

## Features

- Floating stickers over other apps
- GIF and image support
- Drag and drop with one finger
- Pinch to zoom
- Local storage (no servers, no tracking)
- Multi-language support
- Individual on/off switches
- Delete stickers easily
- Adjustable size per sticker

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Database:** Room
- **Image loading:** Coil
- **Overlay:** Foreground Service + WindowManager
- **Min SDK:** Android 8.0 (API 26)
